# 按项目现场继续

1. 先调用 `project_status`（不传 project 就按当前目录找项目），看目标、当前规划、每个任务的状态、"不要做"的已取消事项和下一步建议。
2. 用户指定了任务（编号如 T03，或任务名），调用 `continue_context` 取这个任务的续接上下文；没指定就按下一步建议里的第一条，先和用户确认。
3. 按续接上下文里的"本轮请做"和"完成标准"干活。"不要做"里的事项一律不碰；需求和上下文冲突时先问用户。
4. 做完后说清你怎么验证的、结果如何。不要自己宣布任务完成：Working Corpus 里只有用户确认才算完成，你说"做完了"只会记成待验证。
