# 演示脚本

目标：三分钟内让评委看到三件事：跨工具的项目现场、"AI 说完成"不等于完成、换工具接着干。

## 准备

1. 用团队这次开发的仓库建项目：`npm run gongpai -- project add "Agent 工牌" --dir <仓库目录> --goal "..."`
2. 开发期间在 Claude Code、Codex 里各做过一些事，网页 AI 里讨论过需求的，粘贴导入一段。
3. 演示前点一次"同步"，确认整理完成。推理模型一批要几十秒，别在台上第一次同步。

## 现场

1. **打开项目概览。** 指出最初规划和当前规划不同，点"对比第 1 版"，展示这两天真实改过的方向。
2. **现场让 Claude Code 说"某功能做完了"。** 回到工牌点同步，那个任务变成"待验证"，不是"已完成"。点"依据"，右侧显示 AI 的原话。
3. **点"继续"。** 复制续接上下文，粘进 Codex 的新会话，Codex 直接接着做这个任务。
4. **收尾一句：** 同类工具把记忆塞回给 AI；工牌把项目现场交给人，而且只认证据。

## 备用

- 现场网络不好：`npm run gongpai -- demo` 的示例项目不需要模型，直接能看。
- 被问到准确率：六个样本的评估记录在 `docs/EVAL.md`，样本少，只说明这几种场景没出错，不代表真实准确率。
