## 下一版的轮次

- **第 11 轮 数据纠错（已完成）**：重新整理一个项目（保留你的修正和任务编号）；把误归类的会话移出项目并重新计算，之后同步也不再读它；接入设置显示工具版本。
- **第 12 轮 前端审美（已完成）**：参考 ThreeUI（threeui.com）的深色控制台风格：等宽标签、像素字体呼应 logo、方块状态标记、实心主按钮；新增“语料带”，借 Data Pixel Arc 的像素带，但画的是真实数据。
- **第 13 轮 任务层（已完成）**：页面上拆分任务（把选中的证据拆成新任务）；任务详情显示结果线索（从引用的消息里用规则提取文件路径、提交编号、链接，不用大模型）；续接上下文导出为 Markdown 文件。
- **第 14 轮 来源与决定（已完成）**：导入时可以填原页面链接，原文侧栏能跳回去；决定标出“已被替代”（提示词 v4 + 样本评估）；打开页面自动读取。
- 需求文档 v0.2 的 P0、P1 和补充项到第 23 轮全部完成。之后的工作是真实使用和校准。（Claude Code 插件、Takeout 导入、VS Code 已在第 15 到 18 轮完成；Cursor 按用户决定不做。）
